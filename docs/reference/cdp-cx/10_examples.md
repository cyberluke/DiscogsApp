# Sony CDP-CX S-Link Reference Specification

# 10. Communication Examples

Version: 1.0

Status: Informative

---

# Purpose

This chapter contains complete communication examples observed on
Sony CDP-CX changers.

Unlike previous chapters describing commands and status messages
individually, this chapter demonstrates complete conversations between
Host and Player.

These examples should be used for testing and validating new
implementations.

---

# Notation

Host →

Commands sent to the changer.

Player →

Messages generated by the changer.

Comments

Lines beginning with

#

are explanatory only.

# Validation Checklist

A correct implementation should successfully process all examples in
this chapter without special-case code.

If additional `if (packet == ...)` branches are required for specific
examples, the runtime architecture should be reconsidered.
